
# JavaScript Programming Assignment

This repository contains solutions to 9 JavaScript programming questions.

## Questions

1. Print numbers from 1 to 10 using a loop.
2. Find the sum of elements in an array.
3. Find the largest number in an array.
4. Check whether a number is even or odd.
5. Reverse a string.
6. Merge two arrays using the spread operator.
7. Filter even numbers using ES6 filter().
8. Demonstrate template literals.
9. Convert a normal function into an arrow function.

## Project Structure

- question1.js - Print numbers from 1 to 10
- question2.js - Sum of array elements
- question3.js - Largest number in an array
- question4.js - Even or odd
- question5.js - Reverse a string
- question6.js - Merge arrays
- question7.js - Filter even numbers
- question8.js - Template literals
- question9.js - Arrow function

## Technologies Used

- JavaScript
- Node.js
- Visual Studio Code

## How to Run

1. Install Node.js.
2. Clone or download this repository.
3. Open the project folder in VS Code.
4. Open the terminal.
5. Run any program using:

   node question1.js

Replace question1.js with the file you want to execute.
